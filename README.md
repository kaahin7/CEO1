# GARO Chair Portfolio Form (GitHub Pages)

This folder contains a static, bilingual (Somali/English) form that works on mobile screens.

## Publish it with GitHub Pages

1. Sign in to GitHub and create a new repository named `garo-chair-portfolio-form`.
2. Upload `index.html` to the repository's top level and commit the change.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After GitHub finishes publishing, the link will be `https://YOUR-GITHUB-USERNAME.github.io/garo-chair-portfolio-form/`.

## Important about responses

GitHub Pages only hosts static files. This form does not send responses to you or save them on GitHub. The person filling it should tap **Download answers** and return the downloaded text file to you by WhatsApp or email. Form answers stay in that person's browser until downloaded. Do not publish completed response files in this public repository.

To receive submissions automatically, connect the page to a form service or backend before sharing it.
